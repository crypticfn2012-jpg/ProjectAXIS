Language Reference

Output

Print text to output

say "Hello, World!" say variable say 10 + 5

Variables

Store and use values

let x = 10 let name = "Ron" let arr = [1, 2, 3] x = 20

Math Operators

Basic arithmetic operations

let a = 5 + 3 # 8 let b = 10 - 2 # 8 let c = 4 * 5 # 20 let d = 20 / 4 # 5 let e = 10 % 3 # 1

Comparisons

Compare values (true/false)

x > 5 x < 10 x == 5 x != 3 x >= 5 x <= 10

Logic

Boolean operations

if x > 5 and y < 10 say "Both true!" end if x or y say "At least one true!" end if not x say "Not true!" end

Conditionals

if/else if/else statements

if x > 10 say "Big" else if x > 5 say "Medium" else say "Small" end

Loops

Repeat code N times

loop 5 say "Repeating!" end loop len(array) say "Item!" end

Functions

Reusable code blocks

fn add(a, b) return a + b end let result = add(5, 3) say result

Arrays

Store multiple values

let arr = [10, 20, 30] say arr[0] # 10 say len(arr) # 3 arr[1] = 25 push(arr, 40)

String Operations

Work with text

let s1 = "Hello" let s2 = " World" say s1 + s2 # Concatenate say len(s1) # Length say upper("hi") say lower("HI")

Built-in Functions

Ready-to-use functions

len(x) # Length type(x) # Data type push(arr, val) # Add to array upper(str) # Uppercase lower(str) # Lowercase round(num) # Round number int(x) # Convert to int

Comments

Notes in your code

# This is a comment # Everything after # is ignored say "Code" # Comment here
